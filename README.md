# 🏠 Vacation Rental Dashboard

Dashboard de gestión para 7 pisos en Airbnb y Booking.com.

## 🚀 Despliegue en Vercel

1. Sube estos archivos a la **raíz** de tu repo de GitHub (no dentro de ninguna carpeta)
2. Conecta el repo en [vercel.com](https://vercel.com)
3. Vercel detectará automáticamente Next.js
4. ¡Listo!

## 📦 Instalación local

```bash
npm install
npm run dev
```

## 📁 Estructura

- `src/app/page.js` — Dashboard principal
- `src/components/` — Componentes React
- `src/data/mockData.js` — Datos simulados

## ⚠️ Importante

**NO subas este ZIP como carpeta.** Descomprime y sube los archivos sueltos a la raíz del repositorio.
